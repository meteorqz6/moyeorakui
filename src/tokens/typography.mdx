# Typography

텍스트 스타일은 **Heading**, **Title**, **Body**, **Caption** 4개 그룹으로 구성돼요.
Tailwind v4 진입 CSS에 플러그인을 추가하면 className으로 사용할 수 있어요.

```css
/* 앱의 전역 CSS 진입점 */
@import "@moyeorak/design-system/layers.css";
@import "tailwindcss";
@plugin "@moyeorak/design-system/tailwind-plugin";
@import "@moyeorak/design-system/styles.css";
```

```tsx
<p className="textStyle_body1">텍스트</p>
```
