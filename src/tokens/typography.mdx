# Typography

텍스트 스타일은 **Heading**, **Title**, **Body**, **Caption** 4개 그룹으로 구성돼요.
`tailwind.config.ts`에 플러그인을 추가하면 className으로 사용할 수 있어요.

```ts
// tailwind.config.ts
import moyeorakPlugin from "@moyeorak/design-system/tailwind-plugin"

export default {
  plugins: [moyeorakPlugin],
}
```

```tsx
<p className="textStyle_body1">텍스트</p>
```
