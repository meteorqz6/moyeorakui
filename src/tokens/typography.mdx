# Typography

텍스트 스타일은 **Head**, **Title**, **Body**, **Caption** 4개 그룹으로 구성돼요. Panda CSS의 `textStyle` 속성으로 사용해요.

```tsx
<p className={css({ textStyle: "body1" })}>텍스트</p>
```
