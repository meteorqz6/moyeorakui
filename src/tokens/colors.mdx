# Colors

색상 시스템은 **Palette → Semantic** 두 계층으로 구성돼요.
Tailwind v4 진입 CSS에 플러그인을 추가하면 시맨틱 컬러 토큰을 className으로 사용할 수 있어요.

```css
/* 앱의 전역 CSS 진입점 */
@import "@moyeorak/design-system/layers.css";
@import "tailwindcss";
@plugin "@moyeorak/design-system/tailwind-plugin";
@import "@moyeorak/design-system/styles.css";
```

```tsx
<p className="text-fg-neutral-default">텍스트</p>
<div className="bg-fill-brand-default">버튼</div>
<div className="border-stroke-neutral-subtle">...</div>
```

## Semantic

### Anatomy

시맨틱 토큰은 **[요소]-[의도]-[강조단계]-[상태]** 구조로 구성돼요. 각 토큰은 적용 대상, 의미, 시각적 우선순위, 상호작용 상태를 조합해 일관된 색상 사용 기준을 제공해요.

#### 요소 (Element)

- **fg** — 텍스트, 아이콘 요소에 사용돼요.
- **bg** — 페이지, 섹션, 모달 등 넓은 영역의 배경을 구성하는 데 사용돼요.
- **stroke** — 테두리, 구분선 등 요소의 경계를 표현하는 데 사용돼요.
- **fill** — 배지, 버튼 등 내부가 채워진 독립적 시각 요소의 면 영역에 사용돼요.
- **shadow** — 요소의 깊이감과 계층 구조를 표현하기 위한 그림자에 사용돼요.
- **overlay** — 모달, 바텀시트 등이 활성화될 때 배경을 덮고 레이어를 시각적으로 구분하는 오버레이에 사용돼요.

#### 의도 (Role)

색상이 전달하는 의미와 사용 목적을 정의해요.

- **neutral** — UI 전반에 사용되는 기본 색상 계열로, 중립적인 무채색이에요.
- **brand** — 브랜드 정체성을 표현하기 위해 사용돼요.
- **negative** — 오류, 경고, 위험 상태를 표현하기 위해 사용돼요.
- **positive** — 성공, 완료, 긍정 상태를 표현하기 위해 사용돼요.

#### 강조단계 (Emphasis)

색상의 시각적 강조 수준을 정의하는 8단계예요. `strongest`에 가까울수록 강하게 강조되고, `faintest`에 가까울수록 옅어져 보조적인 정보 표현에 사용돼요.

`strongest` → `stronger` → `strong` → `default` → `subtle` → `subtler` → `subtlest` → `faintest`

#### 상태 (State)

- **pressed** — 사용자가 컴포넌트를 누르고 있는 상태예요.
- **disabled** — 사용이 불가능한 비활성 상태예요.
