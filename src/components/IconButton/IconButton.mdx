# Icon Button

텍스트 라벨 없이 아이콘만으로 특정 액션을 수행하는 버튼 요소에요. 공간이 제한적이거나 사용자가 즉시 이해할 수 있는 표준적인 기능을 간결하고 직관적으로 제공할 때 사용해요.

<br></br>

## Anatomy

<img src={anatomyImg} alt="Icon Button anatomy" style={{ width: "100%", maxWidth: 800 }} />

Icon Button은 Icon을 감싸는 Container로 구성되며, Container는 선택적으로 배경을 가질 수 있어요.

<br></br>

## 사용 예제

### 크기

`IconButton` 컴포넌트의 크기를 변경하려면 `size` 속성을 사용하세요.
접근성과 터치 정확도를 고려하여 24px Icon을 기준으로 터치 영역만 달리한 `sm`, `md`, `lg` 3가지 사이즈를 제공해요.
`sm`은 밀도 높은 UI에서, `md`는 일반적인 터치 환경의 기본 사이즈에요. `lg`는 Action Area 내에서 동일한 높이에 맞출 때 사용해요.

### 스타일

`variant` 속성으로 버튼의 스타일을 설정해요.

- **clear** — 배경 없이 아이콘만 표시해요.
- **fill** — 배경이 채워진 스타일로 아이콘이 강조가 필요한 경우에 사용해요.

<Source of={IconButtonStories.Variants} />

### 상태

Icon Button은 **Default**, **Pressed**, **Disabled** 3가지 상태로 구분돼요.

- **Default** — 기본 상태의 버튼으로, 클릭 가능한 요소임을 명확하게 전달해요.
- **Pressed** — 버튼을 누르고 있는 상태로, 정상적으로 인식되었음을 시각적으로 피드백해요. 버튼을 직접 눌러서 확인할 수 있어요.
- **Disabled** — 비활성화된 상태의 버튼으로, 현재 수행할 수 없는 액션을 의미해요. 사용자의 상호작용을 제한하고 비활성 상태를 시각적으로 전달해요.
