# Floating Button

Floating Button은 화면 위에 떠 있는 형태의 버튼이에요. 스크롤 위로 이동하거나 이전 화면으로 돌아가는 등 자주 사용하는 단일 액션에 사용해요.

## 사용 가이드

<img src={placementImg} alt="Floating Button Placement" style={{ width: "100%", maxWidth: 800 }} />

이 배치 가이드는 `up` 타입 기준이에요.

- 화면 위에 떠 있는 동시에 오른쪽 하단에 20px 마진을 기준으로 일정한 여백을 두고 배치해요. `type="up"`이면 `position: fixed`가 컴포넌트에 내장되어 있어 별도 작업 없이 적용돼요.
- 페이지가 스크롤되어도 화면 우측 하단 동일한 위치에 고정되어 유지돼요.

`back`은 "뒤로 가기"라는 동작 특성상 고정 배치 스펙이 따로 없어요. `type="back"`은 위치가 내장되어 있지 않으니, 실제 고정 위치는 소비 앱에서 직접 배치하세요.

<br></br>

### 접근성

텍스트 라벨이 없기 때문에 `aria-label`이 **필수** 속성이에요. 스크린 리더 사용자가 버튼의 역할을 인지할 수 있도록 액션을 설명하는 문자열을 전달하세요.

```tsx
<FloatingButton type="up" aria-label="위로 이동" />
<FloatingButton type="back" aria-label="뒤로 가기" />
```
