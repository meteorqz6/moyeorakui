# Chip

정보를 선택하거나 콘텐츠를 필터링하는 데 사용하는 컴포넌트에요. 사용자의 선택 상태를 시각적으로 표현하며, 원하는 조건을 설정하거나 해제하는 등의 상호작용을 통해 정보 탐색과 선택 과정을 더 직관적으로 만들어줘요.

<br></br>

## 사용 가이드

<img src={usageImg} alt="Chip Usage" style={{ width: "100%", maxWidth: 800 }} />

- 여러 선택지나 필터 조건을 제공할 때는 2개 이상을 가로로 배열해서 사용해요. 이때 디바이스의 너비를 초과하면 가로 스크롤이 적용돼요.
- 단일 Chip을 단독으로 사용하지 않는 게 좋아요.
- 하나의 Chip에는 하나의 요소만 담아요.
- Label은 사용자가 빠르고 직관적으로 인지할 수 있도록 간결하게 작성하고, 줄바꿈이 발생하지 않도록 해요.

<br></br>

## 사용 예제

### 모양

`shape` 속성으로 칩의 모양을 설정해요. `square`, `pill` 중 하나를 선택할 수 있어요.

<Story of={ChipStories.Shapes} />

<Source of={ChipStories.Shapes} />

### 스타일

`variant` 속성으로 칩의 스타일을 설정해요.

- **Neutral Weak** — 선택되지 않은 기본 상태예요.
- **Neutral**, **Brand**, **Outlined Brand** — 선택된 상태를 표현할 때 사용해요. 강조 수준에 따라 선택해서 사용할 수 있어요.

Chip은 스스로 선택 여부를 알지 못해요. 선택 상태에 따라 어떤 `variant`를 보여줄지는 Chip을 사용하는 쪽(부모 컴포넌트)에서 관리해야 해요.
