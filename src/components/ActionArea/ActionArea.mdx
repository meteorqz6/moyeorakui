# Action Area

화면 및 모달 하단에 고정된 형태로, 현재 맥락에서 사용자가 수행할 수 있는 주요 행동을 버튼 형태로 직관적으로 제공하는 영역이에요.

<br></br>

## Anatomy

<img src={anatomyImg} alt="Action Area anatomy" style={{ width: "100%", maxWidth: 800 }} />

Action Area는 주요 행동을 수행하는 버튼 묶음인 **Button Area**를 필수로 포함하며, 필요에 따라 행동 수행을 돕는 정보를 제공하는 **Supporting Item**을 함께 구성할 수 있어요.

- **Supporting Item** — 사용자가 주요 액션을 이해하고 수행할 수 있도록 부가적인 정보를 제공하는 요소예요. 선택적으로 포함할 수 있으며, Button Area 위에 배치돼요.
- **Button Area** — 버튼이 배치되는 영역이에요. 핵심 행동을 수행하는 Main 버튼이 항상 들어가며, 필요하면 버튼을 하나 더 함께 배치할 수 있어요. 버튼 조합은 아래 Button Area에서 자세히 설명해요.

Action Area는 항상 배경색(`bg.neutral.default`)을 채우므로, 스크롤되는 콘텐츠 위에 고정해도 아래 내용이 비쳐 보이지 않아요.

<br></br>

## Button Area

`type` 속성으로 Button Area의 버튼 조합을 설정해요.

<br></br>

### Main Action

`type="single"`로 설정하면 Main 버튼 하나만 배치돼요. 사용자가 수행해야 할 핵심 행동을 가장 높은 위계로 강조하는 상황에서 사용하며, 불필요한 선택지를 최소화하여 빠른 의사결정과 행동 유도를 목적으로 해요.

<Source of={ActionAreaStories.MainAction} />

### Sub Action

보조 기능을 수행하는 버튼을 Main 버튼과 함께 배치해요. Sub 버튼은 텍스트 버튼 또는 아이콘 버튼으로 표현할 수 있어요.

#### 텍스트 버튼

`type="weighted"`로 설정하면 Sub 버튼과 Main 버튼이 3:7 비율로 배치돼요. 버튼 간 위계를 구분해야 하는 보조 기능 조합에서 사용해요.

<Story of={ActionAreaStories.SubActionText} />

<Source of={ActionAreaStories.SubActionText} />

#### 아이콘 버튼

`type="icon"`으로 설정하면 Icon Button과 Main 버튼이 함께 배치돼요. Icon Button은 고정 크기를 유지하고, Main 버튼이 남는 너비를 채워요.
추가 옵션, 편집, 삭제, 공유처럼 아이콘만으로 의미가 전달되는 보조 기능에 사용해요. Icon Button은 `size="lg"`, `variant="fill"`을 사용해요.

### Alternative Action

`type="equal"`로 설정하면 Alternative 버튼과 Main 버튼이 1:1 비율로 배치돼요. 동일한 중요도의 액션을 제공해야 하는 상황에서 사용해요.

## Safe Area

iPhone처럼 화면 하단에 홈 인디케이터가 있는 기기에서는, 버튼이 홈 인디케이터와 겹치지 않도록 하단 여백을 자동으로 늘려요.
홈 인디케이터가 없는 기기나 데스크톱에서는 기본 여백이 그대로 적용돼요.

모달처럼 화면 하단 끝에 붙지 않는 곳에서는 `safeArea={false}`로 꺼주세요.

> 이 기능이 동작하려면 앱의 viewport 설정에 `viewport-fit=cover`가 포함되어 있어야 해요.
