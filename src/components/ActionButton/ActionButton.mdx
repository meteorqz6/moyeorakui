# Action Button

Action Button 컴포넌트는 사용자가 어떤 액션을 트리거하거나 이벤트를 실행할 때 사용해요. 버튼은 기본적인 UI 요소로, 폼 제출, 다이얼로그 열기, 작업 취소, 삭제와 같은 다양한 액션을 처리하는 데 사용해요.

## 사용 예제

### 크기

`ActionButton` 컴포넌트의 크기를 변경하려면 `size` 속성을 사용하세요. `sm`, `md`, `lg`, `xl` 중 하나를 선택할 수 있어요.

<Story of={ActionButtonStories.Sizes} />

<Source of={ActionButtonStories.Sizes} />

### 레이아웃

텍스트(Label)을 중심으로 구성되며, 필요에 따라 아이콘을 함께 조합하여 사용할 수 있어요.

아이콘은 액션의 의미를 보조하거나 사용자의 빠른 인지를 돕는 역할을 하며, 맥락에 따라 라벨의 앞이나 뒤에 배치할 수 있어요.

`leftIcon`, `rightIcon` 속성으로 버튼의 레이아웃을 설정해요.

아이콘만 단독으로 사용하는 경우에는 Action Button이 아닌 별도의 Icon Button을 사용해요.

<Source of={ActionButtonStories.Layout} />

### 형태

`display` 속성으로 버튼의 형태를 설정해요. `inline`은 다른 요소와 나란히 배치되고, `full`은 부모 요소의 전체 너비를 차지해요.

<Story of={ActionButtonStories.Display} />

<Source of={ActionButtonStories.Display} />

### 스타일

`variant` 속성으로 버튼의 스타일을 설정해요. `default`, `brand`, `brand-weak`, `outline`, `ghost`, `ghost-brand` 6가지가 있어요.

<Story of={ActionButtonStories.Variants} />

<Source of={ActionButtonStories.Variants} />

### 비활성화

버튼을 비활성화하려면 `disabled` 속성을 사용하세요. 비활성화된 버튼은 사용자가 클릭할 수 없고, 시각적으로도 비활성화된 상태임을 나타내요.
