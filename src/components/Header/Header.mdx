# Header

화면 맨 위에 놓여 현재 화면의 제목을 알려주는 영역이에요. 이전 화면으로 돌아가는 버튼과, 화면 단위의 보조 액션 버튼을 함께 배치할 수 있어요.

<br></br>

## Anatomy

<img src={anatomyImg} alt="Header anatomy" style={{ width: "100%", maxWidth: 800 }} />

Header는 높이 56px의 영역 안에 **Title**을 필수로 포함하며, 필요에 따라 **Back Button**과 **Action Button**을 함께 구성할 수 있어요.

- **Back Button** — 이전 화면으로 돌아가는 `IconButton`이에요. 왼쪽에 배치되며, `onBack`을 전달하면 표시돼요.
- **Title** — 현재 화면의 제목이에요. 가운데 정렬되며 `title1` 텍스트 스타일을 사용해요.
- **Action Button** — 화면 단위의 보조 액션을 수행하는 `ghost-brand` `lg` `Button`이에요. 오른쪽에 배치되며, `actionLabel`을 전달하면 표시돼요.

Header는 배경색을 채우지 않아요. 페이지 배경을 그대로 따라가므로 밝은 배경과 어두운 배경 모두에서 사용할 수 있어요.

<br></br>

### 접근성

- 제목은 `h1`으로 렌더링돼요. 한 화면에 Header는 하나만 배치하세요.
- 뒤로가기 버튼에는 `aria-label="뒤로가기"`가 내장되어 있어요.
- 뒤로가기와 액션 버튼은 키보드로 포커스하면 `stroke.brand.default` 포커스 링이 표시돼요.
