# Button

사용자의 액션을 실행하고 시스템과 상호작용하기 위한 기본 인터랙션 컴포넌트이자 핵심 UI 요소에요.
사용자는 버튼을 통해 작업을 수행하거나 다음 단계로 이동하고, 특정 기능이나 화면을 실행할 수 있어요.
완료, 확인, 취소, 삭제, 열기 등 다양한 작업을 직관적으로 인지하고 수행할 수 있도록 지원해요.

<br></br>

## 사용 예제

### 크기

`Button` 컴포넌트의 크기를 변경하려면 `size` 속성을 사용하세요. `sm`, `md`, `lg`, `xl` 중 하나를 선택할 수 있어요.

### 레이아웃

텍스트(Label)를 중심으로 구성되며, 필요에 따라 아이콘을 함께 조합하여 사용할 수 있어요.
아이콘은 액션의 의미를 보조하거나 사용자의 빠른 인지를 돕는 역할을 하며, 맥락에 따라 Leading Icon과 Trailing Icon을 각각 라벨의 앞이나 뒤에 배치할 수 있어요.
`leadingIcon`, `trailingIcon` 속성으로 버튼의 레이아웃을 설정해요.
아이콘만 단독으로 사용하는 경우에는 Button이 아닌 별도의 Icon Button을 사용하세요.

### 스타일

`variant` 속성으로 버튼의 스타일을 설정해요. `default`, `brand`, `outline`, `brand-weak`, `ghost`, `ghost-brand` 6가지가 있어요.

<br></br>

#### Solid

`default`, `brand`, `outline`은 배경 면적과 선명한 대비를 활용한 스타일로, 화면 내에서 높은 주목도를 제공해요. 중요도가 높은 액션이나 핵심 사용자 흐름에 우선적으로 사용하며, 사용자가 인터랙션 요소를 빠르게 인지하고 즉각적으로 행동할 수 있도록 해요.

<Story of={ButtonStories.VariantsSolid} />

<Source of={ButtonStories.VariantsSolid} />

#### Weak

`brand-weak`은 배경 면적이 적용되지만 상대적으로 대비와 채도를 낮춰 시각적 강조를 줄인 스타일이에요. 주요 액션보다는 우선순위가 낮은 보조 액션에 사용하며, 화면 내 위계를 유지하면서도 버튼의 존재를 명확하게 전달해요.

<Story of={ButtonStories.VariantsWeak} />

<Source of={ButtonStories.VariantsWeak} />

#### Ghost

`ghost`, `ghost-brand`는 배경 없이 텍스트 요소만으로 표현되는 스타일이에요. 가장 낮은 수준의 시각적 강조도를 가지며, 콘텐츠 흐름이나 주요 액션을 방해하지 않아야 하는 보조 기능에 사용해요.

### 상태

Button은 **Default**, **Pressed**, **Disabled** 3가지 상태로 구분돼요.

- **Default** — 기본 상태의 버튼으로, 클릭 가능한 요소임을 명확하게 전달해요.
- **Pressed** — 버튼을 누르고 있는 상태로, 정상적으로 인식되었음을 시각적으로 피드백해요. 버튼을 직접 눌러서 확인할 수 있어요.
- **Disabled** — 비활성화된 상태의 버튼으로, 현재 수행할 수 없는 액션을 의미해요. 사용자의 상호작용을 제한하고 비활성 상태를 시각적으로 전달해요.
